BRADLEYGRBL WINDOWS PORTABLE PACKAGE
====================================

1. Extract the entire ZIP before running it.
2. Double-click START_BradleyGRBL.bat.
3. Import an image and use Trace Preview first.
4. Run Outline at 3% only when the engraver is connected and idle.

The outline uses 3% of the controller's configured maximum PWM and physically
moves the machine with the laser enabled. Wear laser safety glasses, clear the
beam path, verify machine origin, and supervise the machine.

Full instructions:
https://github.com/XXKingBradXX/BradleyGRBL/blob/master/WINDOWS_QUICK_START.md

BradleyGRBL is a GPLv3 fork of LaserGRBL.
